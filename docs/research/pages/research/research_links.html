調査サイトリンク集（放射線環境下MOSFET）

放射線耐性半導体（Rad-Hard / Rad-Tolerant）を調査する際に有用なサイトを用途別に整理したページです。

1. 学術・研究論文系

  • IEEE Xplore — IEEE TNS や RADECS 関連論文が充実
  • arXiv（cs.AR / physics.ins-det）— プレプリントで最新研究を先行確認
  • ScienceDirect / Elsevier — Microelectronics Reliability 等
  • ResearchGate — 著者公開PDFや関連ディスカッション
  • Google Scholar — アラート設定に最適

2. 国際会議・ワークショップ

  • RADECS — 欧州の放射線耐性電子系主要会議
  • NSREC — IEEE主催の代表的会議
  • HEART — 宇宙/放射線応用を含む領域も扱う

3. 研究機関・政府機関

  • CERN Document Server (CDS) — 加速器系の耐放射線電子研究
  • NASA NTRS — 宇宙用部品の放射線試験資料
  • JAXA 研究開発資料 — 国内宇宙機器設計関連
  • ESA / ESCC（ESCIES） — 規格・評価情報
  • DTRA — 核・放射線環境耐性の関連情報

4. 業界・メーカー技術情報

  • Texas Instruments — Radiation Hardened 製品情報
  • Renesas — 宇宙/高信頼向け製品情報
  • STMicroelectronics — 宇宙用途ページ・ノート
  • Microchip Technology — 耐放射線製品と技術文書
  • BAE Systems — 宇宙/防衛向けRad-Hard情報
  • Vorago Technologies — 耐放射線MCU関連

5. ニュース・業界媒体

  • EE Times — 半導体/宇宙防衛エレクトロニクス
  • Electronic Design — Rad-Hard 設計関連記事
  • SpaceNews — 宇宙業界動向
  • Military Embedded Systems — 防衛・宇宙向けデバイス動向

6. SNS・コミュニティ

  • LinkedIn — "Radiation Hardened Electronics" などの専門グループ
  • ResearchGate Questions — 研究者Q&A
  • X (Twitter) — #RadHard #RADECS #NSREC

おすすめの活用法

  • Google Scholar で以下をアラート登録: radiation hardened MOSFET, TID MOSFET, SEE MOSFET
