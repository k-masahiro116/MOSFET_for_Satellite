分析手法まとめ

このページは、報告書作成時に使う分析手法を拡張整理した実務用リファレンスです。市場調査で有効な手法を優先表示し、下部に場面別対応表を掲載しています。

優先: 市場調査で有効な分析手法（先に使うべき順）

使い方: まず下記の優先手法を適用し、その後に統計系手法で定量補強する構成が実務で最も再現性が高い。

優先度 分析手法 有効な場面 主なアウトプット
1 TAM/SAM/SOM 市場規模を段階的に絞り込み、参入余地を把握したい 市場規模の3層定義、対象セグメント別売上ポテンシャル
2 3C分析 顧客要求・競合状況・自社強みを同時に整理したい 顧客課題、競合ポジション、自社優位性仮説
3 STP分析 狙う市場とターゲットを明確化したい セグメント定義、優先ターゲット、訴求軸
4 Five Forces 収益性と参入障壁を構造的に評価したい 業界構造の圧力評価、参入/撤退リスク
5 PEST 規制・政策・技術変化が需要に与える影響を見たい 外部環境変化と影響シナリオ
6 SWOT 内部/外部要因を戦略案に接続したい 重点戦略、回避すべきリスク、差別化ポイント
7 ベンチマーク分析 競合比較の説得力を高めたい 比較表、ギャップ分析、優先改善項目
8 シナリオ分析 将来不確実性を含めて意思決定したい 楽観/基準/悲観の3シナリオ別戦略
推奨フロー: 1) TAM/SAM/SOMで市場規模を定義 2) 3C + STPで狙う顧客と勝ち筋を整理 3) Five Forces + PESTで外部圧力を評価 4) SWOT + ベンチマークで戦略を確定 5) シナリオ分析で最終意思決定の頑健性を確認

0. TAM / SAM / SOM（市場規模分解）

目的: 市場機会を「全体→狙う市場→獲得可能市場」で定量化する。

  • 使いどころ: 研究テーマの投資妥当性を初期判断するとき。
  • 注意点: トップダウン値だけでなく、ボトムアップ推計で検証する。
例: 衛星電源向け半導体市場のTAMから、宇宙用途かつ対象電力帯に限定したSAMを算出し、調達可能チャネルを踏まえてSOMを推定する。

0.1 STP分析（Segmentation / Targeting / Positioning）

目的: どの顧客層に、どの価値で勝つかを明確にする。

  • 使いどころ: 市場は広いが、参入リソースが限られているとき。
  • 注意点: セグメントは規模だけでなく、課題の深さと支払意思で評価する。
例: 「小型衛星バス向け高信頼電源」を第一ターゲットに設定し、競合より高い温度耐性をポジショニング軸にする。

0.2 Five Forces（業界構造分析）

目的: 市場の儲けやすさと構造的リスクを見極める。

  • 使いどころ: 参入/撤退判断や価格戦略を検討するとき。
  • 注意点: 競争企業だけでなく、代替技術と買い手交渉力を必ず評価する。
例: 認証ハードルと長期調達要件により新規参入障壁が高い一方、特定顧客への依存で買い手交渉力が高いことを確認する。

1. 記述統計（Descriptive Statistics）

目的: データの全体像を把握する。

  • 算出項目: 平均、中央値、最大/最小、標準偏差、四分位範囲。
  • 使いどころ: 候補比較の初期スクリーニング。
  • 注意点: 外れ値の影響を確認し、中央値も併記する。
例: 候補MOSFET3品番の損失値を比較し、平均と95パーセンタイルで優先候補を絞る。

2. 比較評価マトリクス（Weighted Matrix）

目的: 複数評価軸を統合して順位付けする。

  • 評価軸例: 効率、熱特性、信頼性、コスト、調達性。
  • 使いどころ: 最終候補の選定、採用理由の説明。
  • 注意点: 重み設定の根拠を別表で管理する。
例: 「効率40%、信頼性30%、コスト20%、調達性10%」で総合スコアを算出する。

3. 感度分析（Sensitivity Analysis）

目的: 前提条件の変化が結論に与える影響を確認する。

  • 変動パラメータ: 温度、負荷率、スイッチング周波数、価格。
  • 使いどころ: 条件付き結論の妥当性検証。
  • 注意点: 単一変数だけでなく主要2変数の組み合わせも確認する。
例: 周囲温度を -20°C から 60°C に変化させたときの温度余裕低下量を比較する。

4. リスク分析（Risk Register + Severity/Priority）

目的: 不確実性を可視化して対策優先度を決める。

  • 評価軸: 影響度、発生確率、検出容易性。
  • 使いどころ: 未確定要素が多い初期段階の意思決定。
  • 注意点: 「回避策」「代替案」「トリガ条件」を必ず定義する。
例: 放射線耐性データ未取得を高優先リスクとして登録し、試験計画を先行させる。

5. 市場・競合分析（3C / SWOT / PEST）

目的: 外部環境と競争ポジションを構造化する。

  • 3C: Customer / Competitor / Company の整合確認。
  • SWOT: 内部要因と外部要因を分離して戦略を導く。
  • PEST: 政策・経済・社会・技術の外部変化を整理。
例: 輸出規制の変化（PEST）と競合の調達網（3C）を統合し、調達リスクを評価する。

6. トレーサビリティ管理（Evidence Mapping）

目的: 結論と根拠の対応関係を明確にする。

  • 管理項目: 結論ID、根拠データID、出典URL、取得日、前提条件。
  • 使いどころ: レビュー、監査、将来の改訂。
  • 注意点: 出典更新時に結論への影響評価を必ず実施する。
例: 「結論C-01」は「データD-03」「図F-02」に紐付け、再現可能性を担保する。

7. 仮説検定（Hypothesis Testing）

目的: 差が偶然か有意かを統計的に判定する。

  • 主な手法: t検定、カイ二乗検定、比例差の検定。
  • 使いどころ: 候補間性能差の「有意差」確認。
  • 注意点: p値だけでなく効果量とサンプル数も併記する。
例: 品番A/Bの効率差が統計的に有意かを95%信頼水準で確認する。

8. 回帰分析・相関分析（Regression / Correlation）

目的: 変数間の関係を定量化し、予測や寄与度評価に使う。

  • 主な手法: 単回帰、重回帰、相関係数。
  • 使いどころ: 温度・負荷・周波数が損失へ与える影響分析。
  • 注意点: 相関と因果を混同しない。外れ値と多重共線性を確認する。
例: スイッチング周波数と発熱の関係を回帰式化し設計値に反映する。

9. 分散分析（ANOVA）

目的: 3群以上の平均差を同時に比較する。

  • 主な手法: 一元配置/二元配置ANOVA。
  • 使いどころ: 複数品番や複数条件の比較。
  • 注意点: 正規性・等分散性など前提条件を確認する。
例: 3品番×3温度条件で損失平均に差があるかを評価する。

10. 実験計画法（DOE）

目的: 最小実験回数で要因効果と交互作用を把握する。

  • 主な手法: 直交配列、2水準要因実験、応答曲面法。
  • 使いどころ: 評価条件が多く総当たり困難な場合。
  • 注意点: 因子・水準定義とランダム化順序を明確化する。
例: ゲート抵抗・周波数・温度の3因子が効率へ与える寄与率を算出する。

11. 工程能力/管理図（SPC）

目的: 変動を監視し、異常兆候を早期検知する。

  • 主な手法: X-bar-R管理図、P管理図、Cp/Cpk。
  • 使いどころ: 継続測定の安定監視、品質保証。
  • 注意点: 管理限界と規格限界を混同しない。
例: ロットごとのRds(on)変動を管理図で監視し異常ロットを検知する。

12. パレート分析（Pareto Analysis）

目的: 主要因を絞り、改善優先度を決める。

  • 主な手法: パレート図（件数・損失額ベース）。
  • 使いどころ: 不具合要因やコスト要因の優先順位付け。
  • 注意点: 母集団と期間を固定し、比較可能にする。
例: 熱起因不具合のうち上位20%原因が全体影響の80%を占めるか確認する。

13. 特性要因図（Fishbone / Ishikawa）

目的: 問題原因を構造化して漏れなく洗い出す。

  • 分類軸例: 人・設備・方法・材料・環境・測定。
  • 使いどころ: 原因仮説の整理、レビュー準備。
  • 注意点: 原因候補は事実データで検証可能な形にする。
例: 高温時効率低下の原因を回路・部材・環境要因で分解する。

14. 5 Whys

目的: 表層事象から根本原因へ掘り下げる。

  • 主な手法: 「なぜ」を反復し因果連鎖を明確化。
  • 使いどころ: 単発不具合の初動分析。
  • 注意点: 推測だけで終えず、各段階で証拠を確認する。
例: 試験再現性が低い理由を測定手順・治具状態・校正履歴まで掘り下げる。

15. FMEA（故障モード影響解析）

目的: 故障モードごとのリスクを定量評価し対策優先度を決める。

  • 評価軸: Severity / Occurrence / Detection。
  • 使いどころ: 設計段階での予防的リスク低減。
  • 注意点: 評価基準表を先に定義し、主観差を抑える。
例: ゲート絶縁破壊を高Severity項目として設計マージン増加を優先する。

16. モンテカルロシミュレーション

目的: 入力ばらつきが性能分布へ与える影響を確率的に評価する。

  • 主な手法: 入力分布設定→反復試行→出力分布評価。
  • 使いどころ: 許容差設計、ワーストケース確率評価。
  • 注意点: 入力分布の妥当性とサンプル数を明示する。
例: 部品ばらつきと温度分布を反映し、効率95%保証条件を確認する。

17. ベンチマーク分析（Benchmarking）

目的: 他社・他案とのギャップを定量化する。

  • 比較軸: 性能、コスト、供給性、実績、保守性。
  • 使いどころ: 採用妥当性の外部説明。
  • 注意点: 比較条件を揃え、同等条件で評価する。
例: 宇宙用途採用実績の有無を含めて候補品を相対評価する。

18. シナリオ分析（Scenario Analysis）

目的: 外部環境変化に対する戦略頑健性を確認する。

  • 主な手法: 楽観/基準/悲観シナリオ比較。
  • 使いどころ: 規制変更や供給制約リスクの事前評価。
  • 注意点: シナリオ間で前提を明文化し、混在させない。
例: 輸出規制強化シナリオ時の代替調達可否を評価する。

19. 場面別に有効な分析手法（クイック選定表）

場面 有効な手法 狙い
候補を絞りたい（初期） 記述統計 / パレート / 比較評価マトリクス 短時間で有望候補を抽出する
差が本当に有意か確認したい 仮説検定 / ANOVA 偶然差を排除して判断精度を上げる
要因の影響度を知りたい 回帰分析 / DOE / 感度分析 支配要因を特定し設計最適化する
品質ばらつきを管理したい SPC（管理図） / 工程能力指数 異常兆候の早期検知と安定運用
不具合原因を特定したい Fishbone / 5 Whys / FMEA 根本原因の特定と再発防止
不確実性を含めて評価したい モンテカルロ / シナリオ分析 / リスク分析 将来変動を踏まえた頑健な意思決定
市場・競合を整理したい 3C / SWOT / PEST / ベンチマーク 戦略方針と差別化要因の明確化
監査やレビュー対応を強化したい トレーサビリティ管理（Evidence Mapping） 結論の根拠説明と改訂容易性の確保
